# 🌐 GlobalPulse - Telugu News Scraper

A modern web application for scraping Telugu news from multiple reliable sources.

## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the application:**
   ```bash
   python main.py
   ```

3. **Access the application:**
   - Web Interface: http://localhost:8000
   - API Documentation: http://localhost:8000/api/info

## 📡 API Endpoints

- `POST /scrape` - Scrape news articles
- `GET /sources` - Get available news sources
- `GET /categories` - Get available categories
- `GET /health` - Health check

## 🧪 Testing with Postman

Import the collection: `GlobalPulse-Postman-Collection.json`

## 📰 Features

- 50+ Telugu news sources
- 200+ categories
- Modern responsive UI
- Full content extraction
- Telugu text support
- RESTful API

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Scraping:** BeautifulSoup, Requests
- **UI:** Modern responsive design
