# Review Agent Guide

## Overview

The **Review Agent** is a quality assurance agent that evaluates the Research Agent's responses. It demonstrates **multi-agent collaboration** - a key concept in agentic AI systems.

## What It Does

The Review Agent evaluates research responses based on:

1. **Relevance** - Does it address the query?
2. **Completeness** - Is the information comprehensive?
3. **Accuracy** - Are the facts reasonable and supported?
4. **Structure** - Is it well-organized?
5. **Depth** - Does it provide sufficient detail?
6. **Clarity** - Is the writing clear and professional?

## Output

The Review Agent provides:

- **Overall Rating**: 1-10 scale
- **Satisfactory Status**: Yes/No
- **Strengths**: 2-3 key strengths
- **Areas for Improvement**: 2-3 areas to improve
- **Optimization Suggestions**: Specific, actionable recommendations
- **Summary**: Overall assessment

## Usage

### Standalone Review

```python
from review_agent import ReviewAgent

review_agent = ReviewAgent()
result = review_agent.review(
    query="Your research query",
    response="The research agent's response",
    report_path="path/to/report.md"  # Optional
)
```

### Multi-Agent Workflow

```python
from research_agent import ResearchAgent
from review_agent import ReviewAgent

# Step 1: Research
research_agent = ResearchAgent()
research_result = research_agent.research("Your query")

# Step 2: Review
review_agent = ReviewAgent()
review_result = review_agent.review(
    query="Your query",
    response=research_result["result"],
    report_path=research_result.get("saved_file")
)
```
